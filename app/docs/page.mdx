# 使い方

ディレクトリマップ生成ツールは、Webサイトをクロールして階層構造をExcelとして自動出力するツールです。
サイトリニューアル時のページ棚卸しや、サイトマップの作成・更新に活用できます。

<SampleFile />

## クイックスタート

3ステップでディレクトリマップを生成できます。

### 1. 対象URLを入力

トップページ（クロール設定）で、クロールしたいサイトのURLを入力します。
例: `https://example.com`

### 2. クロール開始

「クロール開始」ボタンをクリックすると、サイトのクロールが始まります。
進捗はリアルタイムで表示されます。

### 3. Excelをダウンロード

クロールが完了したら「Excelをダウンロード」ボタンが表示されます。
クリックするとディレクトリマップのExcelファイルが取得できます。

### 列の詳細

- **No**: 行番号。ページの通し番号です。
- **階層列（トップ / 第2階層 / 第3階層…）**: URLのパス構造に対応した列です。例えば `/about/` は第2階層、`/products/a/` は第3階層に表示されます。
- **URL**: 各ページの完全なURLです。合成ノード（自動補完された中間ディレクトリ）の場合は空欄です。
- **タイトル**: HTMLの `<title>` タグから取得したページタイトルです。
- **ディスクリプション**: HTMLの `<meta name="description">` から取得した説明文です。
- **備考**: 空欄で出力されます。手動でメモを追記するための列です。

### 合成ノード（自動補完）について

クロールで実際のHTMLページが見つからなかった中間パス（例: `/products/` にページがないが `/products/a/` は存在する場合）は、
ディレクトリ名をタイトルとして自動補完されます。この行はURL・ページタイトル・ディスクリプションが空欄になります。
